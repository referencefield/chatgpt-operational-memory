## Authority and supersession

- The user's current explicit instruction wins.
- Active entries in this file govern durable decisions for this project.
- This project's `CURRENT.md` governs transient/current project state.
- Root `DECISIONS.md` governs cross-project/global decisions; if a global decision materially constrains this project, the project front door should make that dependency visible.
- If project current state conflicts with an active durable project decision, surface and reconcile the inconsistency.
- Do not promote ambiguous inference into an active decision.
- When a later decision replaces an earlier one, mark the earlier entry superseded, link both directions, update project current state when needed, and verify consistency before reporting completion.
