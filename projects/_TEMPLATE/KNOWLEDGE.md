## Routing and maintenance

Prefer an existing registered canonical source when one already exists. Do not copy whole documents or duplicate a stronger source just to populate this file.

Current state belongs in `CURRENT.md`. Governing project decisions belong in `DECISIONS.md`. Global collaboration preferences belong in root `WORKING_STYLE.md`.

Supersede corrected knowledge, mark time-sensitive material stale when appropriate, consolidate duplicates, and keep this file compact.

If project knowledge becomes too large or heterogeneous to retrieve and reason about as a single file, register more specific canonical artifacts in `PROJECT.md` or graduate to indexed/structured retrieval rather than splitting files ad hoc.
